## 🧠 How HOPEr Thinks

At its core, **HOPEr** blends emotional intelligence with **Retrieval-Augmented Generation (RAG)** — retrieving real, meaningful knowledge and transforming it into comforting, context-aware guidance.

### 📚 Knowledge Sources
- 🕉️ *Bhagavad Gita* — for spiritual grounding and purpose.  
- 💭 *Mindfulness & Emotional Well-Being Guides* — for coping mechanisms and reflection.  
- 🩵 *Clinical Mental Health Literature* — for safe and evidence-based psychological support.  

### ⚙️ How It Works
1. ✍️ **You Type** — Share your thoughts, worries, or doubts.  
2. 💬 **HOPEr Understands** — Interprets emotion and intent safely.  
3. 🧾 **Knowledge Retrieval** — Uses **Pinecone** to fetch verified information from the vector database.  
4. 🤖 **Response Generation** — **LangChain + GPT** craft a compassionate, grounded reply.  
5. 🕊️ **Emotional Support** — Provides empathy, motivation, and gentle redirection toward hope and help.

## 🏗️ System Architecture
PDF → Text Extraction → Chunking → Embeddings → Pinecone DB
User Query → FastAPI → Pinecone → Retrieve Context → OpenAI LLM → Response → Frontend

✨ This pipeline ensures every answer is grounded in **truth, empathy, and insight** — transforming verified knowledge into words that heal.
